תוכנית פיתוח ואפיון אתר: בחירות 2026
שם האתר: בחירות 2026
תת-כותרת: לא חובה - זכות
מטרת האתר: עידוד הצבעה בבחירות ברמה הלאומית באמצעות דף נחיתה אינטראקטיבי המציג סיטואציות יומיומיות.

1. מבנה קבצי הפרויקט
הפרויקט יחולק ל-4 קבצי אפיון/תוכן מקדימים שינחו את הפיתוח:

Wireframe: תרשים זרימה ופריסה כללית של דף הנחיתה (One Pager), כולל מיקומי מדויקים של הסצנות, בועות הדיבור, אזורי התוכן המתקדמים (Three.js/אינפוגרפיקה) והפוטר.

Design: קובץ עיצוב הכולל פלטת צבעים, טיפוגרפיה, סגנון כפתורים ולוח השראה (Moodboard). לוח ההשראה יציג את הסצנות השונות בהן הדמות המרכזית נמצאת, את המיקומים שלה בכל סצנה ואת מיקום בועות הדיבור/מחשבה.

FirstPrompt: קובץ המתעד את הפרומפט המקורי ואת הגדרות הבסיס של הפרויקט.

Content: קובץ טקסט המאגד את כלל התכנים: סלוגנים, טקסטים לבועות הדיבור בסצנות השונות ("למה הכל כל כך יקר פה?!", "איזה כיף יום חופש!"), שאלות הסקר וקרדיטים.

2. שפה עיצובית (UI/UX) - מתוך קובץ ה-Design
סגנון ויזואלי: קו עיצובי נקי, אקדמי ומקצועי. שימוש באיורים מבוססי וקטור שטוח (Flat Design) ובצורות גיאומטריות.

צבעוניות: פלטת צבעים נגישה עם קונטרסט גבוה (יפורט משתני CSS בקוד).

3. דרישות טכניות לפיתוח (Frontend)
טכנולוגיות: פיתוח ב-Vanilla HTML, Vanilla CSS ו-Vanilla JS בלבד. ללא ספריות חיצוניות (למעט ספריית Three.js אם תיבחר עבור אזור התוכן המתקדם).

הקפדה על HTML:

שימוש במסמך תקין עם הצהרת <!DOCTYPE html>.

חלוקה נכונה ותקינה של תגיות html, head, body.

שימוש בתגיות סמנטיות: <header>, <nav>, <main>, <section>, <article>, <footer>.

הגדרת טקסט חלופי (alt) אינפורמטיבי לכל התמונות והאיורים באתר.

קישורים פנימיים (לניווט עוגנים) וחיצוניים (לאתר ועדת הבחירות) תקינים ונגישים.

קוד נקי משגיאות (Valid HTML).

הקפדה על CSS:

שימוש בקובץ CSS חיצוני אחד בלבד (style.css), אליו מקושר קובץ ה-HTML.

הגדרת משתני CSS (Custom Properties) ב-:root עבור צבעים, פונטים ומרווחים, לשמירה על כתיבה מסודרת.

הימנעות מוחלטת מכפילויות בקוד.

שימוש נכון במודל הקופסה (Box Model).

עימוד הדף יתבצע באמצעות Flexbox או CSS Grid (display).

שימוש ב-position: sticky או fixed עבור ההאדר, ו-absolute למיקום מדויק של בועות הדיבור על גבי האיורים.

שמות מחלקות (Classes) ברורים ומשמעותיים, ללא שימוש מיותר במזהים (IDs) לעיצוב.

אינטראקציה ואנימציה (JS & CSS):

גלילה חלקה: שימוש ב-scroll-behavior: smooth ב-CSS למעבר רך בין חלקי האתר.

אנימציות בועות דיבור: טקסטים בבועות יופיעו בהנפשת עמעום (Fade-in) כאשר המשתמש יגלול למטה והסצנה תיכנס לשדה הראייה (באמצעות IntersectionObserver ב-JS).

אפקט ריחוף (Hover): בעמידה עם העכבר (Hover) על בועות הדיבור, תתווסף אנימציה עדינה (למשל transform: scale(1.05)) להדגשת הבועה.

נגישות (WCAG 2.1) ורספונסיביות:

רספונסיביות מלאה לכל גדלי המסכים (Mobile, Tablet, Desktop) בעזרת Media Queries.

עמידה מלאה בתקן נגישות: קונטרסט צבעים תקני, אפשרות ניווט מלאה באמצעות המקלדת (Tab), ופוקוס ברור על אלמנטים לחיצים (סקר, כפתורים, קישורים).
